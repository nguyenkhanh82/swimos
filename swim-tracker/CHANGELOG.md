# Changelog

All notable changes to SwimTrack Pro will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/).

---

## [Unreleased]

### Added
- Training set recording with individual split times
- Training Sets tab on Times page with tabbed navigation
- Weekly training volume summary (distance and sets count)
- Expandable split times view for each training set
- Pool type filter (All, LCM, SCM, SCY) on Goal Progress chart
- Edit functionality for existing swim goals (change target time or pool type)
- Pool type badge display on goal progress cards
- Comprehensive technical documentation in `docs/README.md`
- CHANGELOG.md for tracking all project changes

### Changed
- Times page now has tabs for "Race Times" and "Training Sets"
- Goal Progress component now shows pool type alongside event name
- SetGoalDialog supports both create and edit modes

---

## [1.0.0] - 2025-12-08

### Added
- Initial release of SwimTrack Pro
- User authentication with email signup/login
- Swim time tracking with personal records
- Time converter between LCM, SCM, and SCY
- Meet management with entries and results
- Nutrition tracking with meal logging
- AI-powered meal plan generation
- AI-powered race plan generation
- Dashboard with training analytics
- Goal setting for swim events
- PWA support for mobile installation
- Responsive design for all devices
